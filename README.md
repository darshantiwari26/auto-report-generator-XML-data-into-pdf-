# NIET Auto Report Generator

A PHP/XAMPP project that converts XML datasets into attractive formatted HTML reports and downloadable PDF reports.

## How to Run in XAMPP

1. Copy this project folder into `C:\xampp\htdocs\niet-auto-report-generator`.
2. Start Apache from the XAMPP Control Panel.
3. Open `http://localhost/niet-auto-report-generator/` in your browser.
4. Upload an XML file, or use `sample-data.xml` to test.

## Features

- XML upload validation.
- Automatic report summary from XML root, attributes, and fields.
- Dynamic tables for nested XML records.
- Attractive responsive UI.
- Browser print/save as PDF.
- Server-side PDF download through `report_pdf.php`.
